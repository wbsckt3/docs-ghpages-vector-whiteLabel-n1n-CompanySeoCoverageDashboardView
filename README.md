## Qué incluye

- Concepto **Coverage Engine** (vs SEO dashboard clásico)
- Guiño filosófico a Y Combinator (entrada simple → crecimiento compuesto)
- Comparativa 2 URLs → matriz DOFA → plan PDF/.md
- Import GSC y diff GSC ↔ sitemap ↔ crawl
- Ciclo Discover → … → Learning
- Features y secciones del dashboard white label
- Logo P2L + Y invertida + combinator (misma marca que el login)
- **Planes** (Gratis / Plan 1–3) alineados al dashboard ePayco
- **Manual de usuario** (`manual.html`) con botón “Manual PDF” (imprimir / guardar PDF)
- Biblioteca de ilustraciones isométricas (mismo estilo) en `assets/illustrations/`:
  hero, how-it-works, gsc, analyze, engine, score, compare, plan, benefits, footer
- La imagen panorámica completa queda de archivo en `assets/seo-coverage-hero-isometric.png` (no se usa como pieza única en la landing)
